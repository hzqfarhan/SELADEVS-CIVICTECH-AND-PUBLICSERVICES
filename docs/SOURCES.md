Public instance, no configured API key. Availability has no application-controlled SLA. Style-linked resource URLs are resolved by MapLibre, not hard-coded API assumptions.

### [OpenStreetMap](https://www.openstreetmap.org/copyright)

Roads, place labels and geographical basemap information through OpenFreeMap.

© OpenStreetMap contributors, ODbL. The application preserves on-map attribution and does not bulk-cache third-party tiles.

### [OpenMapTiles / OpenFreeMap attribution](https://openfreemap.org/quick_start/)

Vector tile schema and basemap attribution.

MapLibre displays the attribution supplied by the provider. The active 3D map uses OpenStreetMap building footprints and provider render heights (which may be estimated). No surveyed terrain is claimed.

### [GERAK community reports](/api/reports)

User-submitted geotags, descriptions, optional images and operator status changes.

Application-owned data in local JSON or PostgreSQL/PostGIS. Not a Malaysian municipal API. No synthetic reports are seeded. Reports are public; images are re-encoded client-side.

### [UTHM KATSANA tracker](https://uthm.katsana.com/)

Published Batu Pahat and Pagoh route paths and checkpoint coordinates.

Public page inspected 1 October 2026; three routes saved in /data/uthm-katsana.json. Public WebSocket responds, but no live adapter is connected. Vehicles and durations remain simulated; no redistribution licence identified.

## Standards and documentation

### [DOSM boundary data provenance and licence](/data/boundaries/provenance.json)

Exact source URLs and hashes for the bundled country, state and district files.

Publisher: Department of Statistics Malaysia. Geometry is preserved; files are only JSON-minified. Permission and disclaimers follow the publisher's Open Data License.

### [Next.js PWA guide](https://nextjs.org/docs/app/guides/progressive-web-apps)

App Router manifest and service-worker integration.

The matching installed Next.js documentation was also read locally under node_modules/next/dist/docs/.

### [GTFS Schedule specification](https://gtfs.org/documentation/schedule/reference/)

CSV field and coordinate interpretation.

Includes service-day time semantics. Calendar-aware routing and all-trip shape matching remain future work.

### [GTFS Realtime specification](https://gtfs.org/documentation/realtime/reference/)

VehiclePosition protobuf semantics and optional fields.

Omitted occupancy and speed are unknown, not invented observations. The national integration uses VehiclePosition only.

### [data.gov.my realtime documentation](https://developer.data.gov.my/realtime-api/gtfs-realtime)

Supported agencies, update frequency and feed limitations.

Documents approximately 30-second updates. No connected national TripUpdates or ServiceAlerts endpoint is claimed.

### [data.gov.my static documentation](https://developer.data.gov.my/realtime-api/gtfs-static)

Official static endpoints and refresh guidance.

Used for all registered BAS.MY cities, KTMB and Prasarana categories. Rapid KL rail has static schedules only; no stable realtime endpoint is claimed.

### [data.gov.my rate limits](https://developer.data.gov.my/rate-limit)

Upstream request budgeting.

Published limit: 4 requests per minute. In-process coalescing is implemented; multiple production replicas require a shared ingestion owner/cache.

### [data.gov.my FAQ / licence](https://developer.data.gov.my/faq)

Government open-data attribution.

CC BY 4.0. Field transformations and runtime source timestamps are documented.

### [Open311 GeoReport v2](https://wiki.open311.org/GeoReport_v2/)

Civic service-request interoperability reference.

No municipal Open311 gateway is connected. GERAK does not claim Open311 conformance.

## Application-owned APIs

| Endpoint | Data |
| --- | --- |
| `GET /api/vehicles` | Selected operator vehicle positions; Johor by default; explicit `mode=demo` simulator |
| `GET /api/network` | Selected operator official topology; UTHM region is a demo topology |
| `GET /api/events` | Server-Sent Events for positions and report changes |
| `GET/POST /api/reports` | Public civic records and validated submissions |
| `PATCH /api/reports/:id` | Authenticated status transitions |
| `GET/POST/DELETE /api/session` | Operator session state, login and logout |
| `GET /api/health` | Process/storage selection/feed-cache diagnostics, not database readiness |
| `GET /api/sources` | This provenance registry |
| `GET /api/feeds` | Service registry, upstream URLs and update intervals |

Full contracts: [API.md](API.md). These endpoints are implemented by GERAK, not external Malaysian authorities.

## Original and unavailable material

- GERAK logo, CSS layout, procedural city, vehicle meshes and simulator are original implementation assets; no Jalan KL or Abeto artwork/models were copied.
- DM Sans and Space Grotesk are packaged locally through Fontsource; no Google Fonts runtime request remains.
- The shared ChatGPT conversation could not be fetched; unseen content was not used.
- `Downloads/codefest26-master.zip` was inspected as an event website source archive, not an authoritative uploaded judging brief. No separate CODEFEST brief was available.
- The initially attempted CARTO raster URLs returned authorisation-required tiles in visual testing. They were removed from runtime code and replaced with OpenFreeMap. They are not a current dependency.
- No Mapbox token/API, Google Maps API, external AI API, weather feed, municipal gateway, KATSANA telemetry or paid routing API is configured.
- Official vehicles, stops and routes are real source data. The 3D buildings are illustrative; generated block placement is not surveyed building or terrain data.
- The app calculates only bounded route-connection ride-time estimates, not operator ETA, timetable departures, fares, guaranteed accessible journeys or delay predictions.
